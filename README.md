# Registration Form

A web-based Registration Form developed to collect and store user information in a structured manner.

## Technologies Used

- HTML
- CSS
- PHP
- MySQL

## Features

- User registration form
- First name and last name
- Email address
- Phone number
- Gender selection
- Date of birth
- Password
- Confirm password
- Form validation
- Database connectivity
- Data storage in MySQL

## Project Description

The Registration Form is a web-based application designed to collect user information through an online form.

HTML is used to create the structure of the form, CSS is used for styling, PHP is used for server-side processing, and MySQL is used to store the submitted information.

## Database

MySQL is used to store and manage registration details submitted through the form.

## Project Purpose

The purpose of this project is to understand HTML forms, CSS styling, PHP form processing, MySQL database connectivity, and basic database operations.
